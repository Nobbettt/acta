# Maintainers

The repository owner, [@Nobbettt](https://github.com/Nobbettt), is the current
maintainer and release authority.

Maintainers review contributions, decide compatibility policy, triage reports,
and execute releases. Changes to stable schemas, release automation, licensing,
or supported agent behavior require maintainer review. A maintainer must not
approve their own release-critical change without the required CI evidence.

Future maintainers should be added here in the same pull request that grants
repository permissions. If governance expands beyond one maintainer, this file
must define review quorum, inactivity/removal, and release-key ownership before
the new policy takes effect.
