# Code of Conduct

We want Acta's community to be useful, welcoming, and technically rigorous.
Participants must communicate respectfully, assume good faith while still
challenging ideas with evidence, respect privacy, and avoid harassment,
discrimination, threats, sexualized attention, or publishing another person's
private information.

This applies in repository discussions, reviews, project events, and other
spaces where someone represents Acta. Maintainers may edit or remove content,
close discussions, issue warnings, or temporarily/permanently restrict
participation when behavior undermines a safe and productive community.

Report conduct concerns privately to the repository owner through the contact
method on their GitHub profile. Do not open a public issue containing personal
or sensitive details. Reports will be reviewed promptly, confidentially, and
without retaliation. If the repository adds a dedicated conduct address, this
file will be updated before it is used as the primary reporting channel.
