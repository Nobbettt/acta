# Support

Use GitHub Discussions, when enabled, for usage questions and integration
help. Until then, open a question using the repository issue chooser and
include `acta version`, the agent CLI and version, operating system, the exact
command shape with credentials removed, and the smallest reproducible example.

Use the bug form for reproducible Acta defects and the feature form for design
proposals. The project is maintained on a best-effort basis and does not offer
response-time or compatibility SLAs. Supported versions and platforms are
those stated in the current README and release notes.

Potential vulnerabilities do not belong in public support channels; follow
[SECURITY.md](SECURITY.md). Conduct concerns follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
